# AI-Powered Recipe Generator

## Overview

This project is an AI-powered Document Q&A RAG Recipe Generator developed using IBM LangFlow, IBM Granite Models, IBM watsonx.ai, and Retrieval-Augmented Generation (RAG).

## Features

- Recipe Document Search
- Conversational Recipe Q&A
- Personalized Recipe Recommendations
- Ingredient Substitution
- Shopping List Generation
- Nutrition Facts
- Step-by-Step Cooking Guide

## Technologies Used

- IBM LangFlow
- IBM Granite Models
- IBM watsonx.ai
- Retrieval-Augmented Generation (RAG)
- HTML
- CSS
- JavaScript
